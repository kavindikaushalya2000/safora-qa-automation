# safora-qa-automation
Automated UI testing suite for the Safora Contact Us form developed with Playwright using the Page Object Model architecture.

## Framework Architecture
This project is built using Playwright with the Page Object Model (POM) design pattern to ensure clean, maintainable, and human-readable test scripts.

## Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## How to Run the Script

1. Clone the repository:
  bash
   git clone <your-github-repo-url>
   cd safora-qa-automation
